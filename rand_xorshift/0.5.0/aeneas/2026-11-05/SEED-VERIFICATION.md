# Exact initialization from every 16-byte seed

Kani 0.68.0 / CBMC 6.11.0 checks the unchanged rand_xorshift 0.5.0 `SeedableRng::from_seed` implementation for every `[u8; 16]` value. Four little-endian u32 values are constructed from independent byte-concatenation formulas. If all four are zero, all four internal words become `0x0BAD5EED`; otherwise the words are retained exactly. The constructed internal state is not all zero.

The original entire src/lib.rs is embedded byte-for-byte as a verification module prefix. Only a safe state observer invoking the original constructor is appended, so the implementation body is not rewritten. build.rs and source-provenance.json retain the relationship; root original source and Cargo.toml are unchanged. The module is compiled in a std verification harness while using the same explicit core imports and rand_core 0.10.0 dependency. This is a direct Kani body check, not an Aeneas seed theorem.

The seed's 16-byte length is fixed by the public API. Harness unwind=20 covers the four-word loop and 16-byte memcmp operations; unwinding assertions remain enabled and pass. It is not an assumption restricting arbitrary seed values. An initial unwind=10 run exposed an insufficient memcmp bound; the completed run uses 20. Seed result: 237 checks, zero failures, five unreachable. A portable rerun using the artifact-relative original source also succeeded, and its generated prefix was byte-compared after the run.

Kani uses Rust nightly-2026-08-21, distinct from the Aeneas extraction nightly. A second original-body observer invokes try_next_u32 on every four-u32 internal state under the explicit precondition that it is not all zero. The next internal state remains nonzero: 90 checks, zero failures, one unreachable. Together the seed and preservation facts support a nonzero-state invariant under repeated next_u32 transitions. They do not establish period, distributions, output independence or cryptographic properties. from_rng/try_from_rng callbacks, seed_from_u64 defaults, serde and exact arbitrary output histories are not proved here. The combined supplementary run has two harnesses and 327 checks, zero failures; both observers preserve the entire original implementation prefix. Aeneas's original-seed extraction remains tool-blocked by mutable zip iteration.

## Lean transition preservation

Nonzero.lean proves the nonzero-state invariant from the existing Aeneas exact original-body transition theorem. The proof uses shift nilpotence: t XOR (t >> 8)=0 implies t=0 by shifting twice more to width 32, and x XOR (x << 11)=0 implies x=0 by shifting to width 33. It uses ordinary BitVec equalities, not native decision axioms. Both the independent bitvector lemma and its connection to the original next_u32 translation audit to propext, Classical.choice and Quot.sound only. The source next_u32 body remains conditional on the previously supplied three std wrapping models. The seed initialization guarantee is still the independent Kani result, not a newly claimed Aeneas seed proof.
