## Evidence and review state

- `dashboard.json`: metric definitions, per-crate axes and SHA-256-identified source inventories.
- `api-observations.json.gz` and `observations/<crate>.json.gz`: normalized observations, complete self/trait/generic signatures, origins, source references, existing guarantees and remaining obligations. These gzip JSON files are downloadable machine-readable data.
- `inventory-snapshots/*.gz`: exact worker JSON snapshots; decompression recovers the SHA-256 listed in `dashboard.json`. Each normalized observation identifies its input snapshot, section and record index.
- `proof-updates.json`: new proof registrations after source/specification/body/domain/model/axiom/integration review. Unregistered or unfinished work is not counted as a new guarantee.
- `inventory-schema.md` and `identity-and-publication.md`: the common scope and publication identity limitations.

An unassessed closure is not a retraction of an existing theorem. Structural and dependency obligations are never silently dropped from the denominator.
