Full-public-API completion is not claimed. CloneToUninit2 still lacks arbitrary valid destination coverage. The fresh symbolic Layout experiment failed a pointer-offset address-consistency guard for Rand32 (one of105 checks); Rand64 was not started. Changing object bits16→8 retained the same failure; neither run establishes a crate defect or a heap-region contract. Existing fixed-slot successes remain valid. Generic6 production binding is also pending. Borrow/identity and other tools retain their explicit modeled-value/reference/effect boundaries; target/compiler/resource behavior is not globally verified.

Range general termination is not a missing proof to demand: the accepted restored-zero-state counterexample diverges. The published exhaustive exact trace specification describes finite acceptance or divergence instead. Uniformity and period are separate properties, not silently included.
