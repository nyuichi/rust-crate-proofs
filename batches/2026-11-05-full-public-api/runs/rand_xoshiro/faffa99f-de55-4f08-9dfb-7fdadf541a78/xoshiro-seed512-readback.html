Overview

For rand_xoshiro 0.8.1 on x86_64 with default or serde features, 69 scoped contracts specify exact outputs and state updates for every internal word pattern, including zero states. Thirty-five direct original-body contracts cover native outputs, all fifteen little-endian state serializers, and Seed512 zero initialization, byte views, legal fixed-length mutable writeback and iterator initialization. Nine compiler-inlined original calls cover 64-to-32-bit projections: xoroshiro128++ and xoroshiro128** use low output bits; the other seven use high bits. Twenty-five further compiler-inlined calls cover the external rand_core 0.10.1 blanket Rng::next_u32/next_u64 specializations, preserving the exact original forwarding behavior and full resulting state. These are external trait specializations, not local declarations. The original selected translations agree under default and serde features; serde implementations themselves are not proved. Eleven two/four-word serializers use the explicitly bounded U32/U64 primitive layout dictionaries; three eight-word serializers prove termination of the original serialization loop. Separate Kani seed/state/composition results remain supplementary evidence, not additional Aeneas claims. Separately, two original-Rust Kani/Z3 harnesses cover the public Seed512 tuple-constructor operation for every64-byte input. Constructing Seed512(bytes) preserves all64 bytes in its public field and actual AsRef view. For every independent64-byte replacement, copying it through the constructed value's actual AsMut slice writes exactly those bytes back to its public field and AsRef view. These84 successful checks concern a data constructor operation, not a fabricated associated function or a new registered API claim. Existing Default, AsRef, AsMut and iteration mappings are observations/composition here and are not counted again.
