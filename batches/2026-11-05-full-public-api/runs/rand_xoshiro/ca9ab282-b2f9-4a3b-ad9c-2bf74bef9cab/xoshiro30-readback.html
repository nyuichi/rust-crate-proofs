Overview

For rand_xoshiro 0.8.1, the unchanged native word-generating method of each of its fifteen generators returns Ok of the specified output scrambler and performs the exact documented word-state transition. Coverage includes SplitMix64, both xoroshiro64 variants, all three xoroshiro128 variants, and all three variants of each xoshiro128, xoshiro256 and xoshiro512 family. For 32-bit-word engines the native method is try_next_u32; for 64-bit-word engines it is try_next_u64. SplitMix64::try_next_u32 is also proved independently, including its distinct Mix4 output formula, among the direct body proofs. Each theorem covers arbitrary internal words, including all-zero states, and establishes normal termination in the Aeneas model. Array-state representation theorems establish that the four-word and eight-word inputs cover every valid fixed-length engine state. Exact output formulas and resulting fields are defined independently of the generated Rust body in the output*/next* specifications. The selected original bodies have byte-identical official Aeneas translations under the default and serde feature configurations, so these body guarantees apply to both configurations; this does not verify the serde trait implementations. Nine further 32-bit APIs are verified through exact forwarding selectors whose calls to the unchanged original API are inlined by the Rust compiler: all three xoroshiro128, all three xoshiro256 and all three xoshiro512 variants. These establish the same state transition as their 64-bit method, with low 32 output bits for xoroshiro128++ and xoroshiro128**, and high 32 bits for the other seven variants. The selector source, typed receiver/return correspondence, target, original method inline scopes and absence of unknown externals are guarded. Default and serde selected programs are byte-identical. Four additional direct body proofs cover Seed512: Default initializes all 64 bytes to zero; AsRef exposes exactly the stored bytes; AsMut exposes those bytes and writes back every legal 64-byte replacement unchanged; iter initializes the standard slice-iterator model over those same bytes at position zero. SplitMix64::state is additionally proved to return exactly the eight little-endian bytes of its complete internal u64 state, for every state including zero. Thirty registered APIs comprise twenty-one direct bodies and nine compiler-inlined calls. Separate Kani evidence checks the five remaining 32-bit-engine try_next_u64 APIs against independent two-step little-endian word composition and exact poststate formulas for every internal state, including zero, under default and serde features. Each configuration passes five ordinary harnesses and 892 checks. These are separate Kani guarantees, not Aeneas machine claims or a cross-tool equivalence theorem.
