Overview

For either 1.19.0 with default features on x86_64, is_left/is_right identify the actual branch; left/right return the corresponding optional payload; left_or/right_or select that payload or the given default; flip swaps the branch and a separate composition theorem proves flipping twice returns the original value. left_and/right_and select the supplied value or preserve the opposite payload. factor_none moves the optional payload outside Either while retaining its tag. factor_first/factor_second move the common tuple component outside Either. as_ref preserves the variant and referenced value; as_mut preserves the initial view and its generated backward function writes a matching-variant replacement payload back to the original variant. The fourteen original bodies terminate normally in the model for all well-typed values in their stated domains.
