Overview

For oorandom 11.1.5, twelve original integer/state APIs have exact value/state proofs for every scalar input, including zero states and even restored increments. For both Rand32 and Rand64, new_inc sets increment to ((input_increment << 1) OR 1), advances from zero, adds the seed with wrapping arithmetic, then advances again; new uses DEFAULT_INC. state and from_state preserve the complete state/increment pair, with save/restore identity. Unsigned generation returns the specified PCG-XSH-RR permutation of the old state and advances to multiplier*state+increment modulo the state width. Signed generation returns the same output bits interpreted as i32/i64 and preserves that updated state. These calls terminate normally in the extracted model.

Separate Kani results cover both original rand_float methods for every complete state/increment pair. They return exactly n/2^24 or n/2^53, where n is the top24 or53 bits of the corresponding unsigned word, with the exact independent IEEE encoding and a value in [0,1). Their complete poststate equals an actual unsigned-word call. This follows from successful original-float/helper and all-word/helper specifications on the identical Rust helper; a direct Rand32 check independently confirms the same contract. State equality alone is not a call-count proof; original source/LLBC observations separately identify the sole word call.

Both original rand_range methods now have exact trace contracts in the extracted debug model. For valid width=end-start, each candidate consumes the next actual PCG word and advances the actual generator. If candidate n is accepted and every earlier candidate rejects against the proved canonical threshold, sampling returns exactly floor(product_n/2^b)+start and the candidate state after n+1 words, where b is32 or64. If every candidate rejects, it diverges. The classical first-accepted-or-all-rejected case split is exhaustive, not an executable termination decision. The specification’s auxiliary typed width must equal end.val-start.val. Invalid start>=end ranges produce assertion failure. Prior no-failure/normal-return bounds/increment preservation and the publicly restored(0,0) range0..3 divergence result remain included; constructor reachability of that pair is not claimed.

Additional Kani checks establish From<Self>, Borrow<Self> and BorrowMut<Self> identity and mutable replacement propagation for every public state/inc pair; Any matches its own TypeId and distinguishes Rand32 from Rand64 without changing state. CloneToUninit preserves the source and copies its complete state into a distinct valid aligned MaybeUninit stack slot.

Six generic conversion families have conditional original-body Lean contracts: Into delegates to From; TryInto forwards the complete TryFrom result; blanket TryFrom delegates to Into and wraps a normal result in Ok. Modeled failure/divergence propagate. These require the actual Rust trait bounds and matching dictionaries, not arbitrary conversion correctness or termination. TryFrom uses official generation; the four Into/TryInto owner specializations additionally use a separately pinned finite export-only translator patch, with the trust boundary below.
