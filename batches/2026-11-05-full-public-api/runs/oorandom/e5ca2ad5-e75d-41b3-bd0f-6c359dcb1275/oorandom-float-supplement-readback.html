Overview

For oorandom 11.1.5, twelve unchanged APIs have exact value/state proofs: new, new_inc, state, from_state, the unsigned output method and the signed output method for both Rand32 and Rand64. For arbitrary seed and increment input, new_inc normalizes the stream to ((increment << 1) OR 1), starts at zero, performs one PCG state update, adds the seed modulo the state width, then performs a second PCG state update. new uses the published DEFAULT_INC. state returns the exact current state and increment, and from_state restores those values unchanged; two additional composition theorems establish save/restore identity. Unsigned generation returns the exact PCG-XSH-RR output permutation of the old state and advances to multiplier*state+increment modulo 2^64 or 2^128. Signed generation preserves that updated state and reinterprets the unsigned result bits as i32 or i64. Each covered call terminates normally in the Aeneas model for every scalar input, including zero states and even restored increments. Separate Kani harnesses directly check both original rand_float methods after restoring arbitrary complete state and increment, including zero states and even increments. Each returns an IEEE value greater than or equal to zero and strictly less than one (two harnesses, 33 checks each). This is a separate range-only body guarantee; exact float bits and poststate were not established, and no cross-tool equivalence or Aeneas machine claim is added.

Technical limitations

The proof covers twelve integer/state APIs on x86_64-unknown-linux-gnu with the original default configuration. Exact rand_float output bits/poststate and rand_range for both generators remain unproved; separate Kani evidence establishes only the rand_float output range, as do non-excluded inherited/default and external blanket methods. The save/restore composition theorem establishes pure state identity; no arbitrary user callback or destructor behavior is modeled. No period, statistical distribution, independence or cryptographic guarantee is established. Other targets were not checked.
