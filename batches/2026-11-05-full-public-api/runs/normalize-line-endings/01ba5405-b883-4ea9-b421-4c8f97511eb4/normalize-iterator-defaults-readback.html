Overview

For every finite character list, the Aeneas translation of normalize-line-endings 0.3.0's adapted normalized constructor and Iterator::next returns exactly the list obtained by replacing each CRLF pair and each remaining CR with LF, while preserving other characters. The proof uses a total, fused list iterator and an observation budget greater than the input length, with no fixed input bound. The output contains no CR, is no longer than the input, and is unchanged by another normalization pass. The constructor and next bodies are dependencies of the checked public theorem. Extraction required replacing three character patterns with equality guards. Kani additionally checks one-step equivalence of the actual original and adapted next bodies for both prior-state flags and all possible character replies in a non-panicking two-reply iterator trace model: returned value, adapter state, callback count, and remaining modeled iterator state agree. The Aeneas theorem applies to the adapted extraction. Separate original-source evidence now proves the unchanged normalized constructor directly with official Aeneas: for every translated iterator and Iterator dictionary it returns that iterator and initializes the previous-CR flag to false. This says nothing about later next calls. Independently, Kani checks original iterator outputs for lengths zero through four and every valid Unicode scalar value against an eager CR/LF/CRLF reference: exact output, no CR, nonincreasing length, idempotence, two exhausted None replies, and the initial inherited Iterator size_hint default. The Kani input iterator is total and finite; unwind bound eight retains unwinding assertions (437 successful checks). These original-source supplements are distinct from the one adapted-source machine claim. Further original-source Kani checks execute actual inherited Iterator::nth/count/last defaults and original next on a concrete fused input with0..4 characters drawn from every Unicode scalar. Every usize nth index, including usize::MAX, is covered: nth returns the independent normalized reference element and remaining suffix with persistent EOF; count returns its exact length and last its exact final element.

What is trusted

The Rust compiler, Charon/Aeneas translation, their standard-library models, and the Lean kernel are trusted; the supplementary equivalence result also trusts Kani/CBMC and its Rust compilation/modeling. The input iterator is modeled as consuming one character per successful call and returning None permanently after exhaustion. No additional local axioms are used; the public theorem depends only on Lean's propext, Classical.choice, and Quot.sound.

Technical limitations

The original crates.io source is retained unchanged, but its character-pattern switches are unsupported by the pinned Aeneas translator. The three guard replacements have a Kani-checked one-step equivalence under the documented two-reply, non-panicking callback model. This is not a generic contextual-equivalence proof for every Rust Iterator implementation, nor a direct arbitrary-length Aeneas proof of the unmodified iterator next body. The original constructor alone is separately body-proved; bounded original iterator Kani behavior does not establish arbitrary-length or arbitrary-callback behavior. The end-to-end Aeneas guarantee remains scoped to the adapted extraction and total fused list iterator model. Arbitrary external iterators, their panics or divergence, and iterators that resume after None are outside the end-to-end theorem. No separate general memory-safety claim is made. The inherited-default supplement is restricted to this concrete fused input and length0..4; the nth index itself is unbounded over usize. It does not establish arbitrary input lengths or Iterator implementations, other defaults, generic contextual equivalence or an original arbitrary-length next theorem. It adds no Aeneas mapping and does not broaden the adapted-source primary theorem.

Tool limitations

Lean backend only, requiring cargo-proofs 0.4.0 or later. The version identifies the official Aeneas Git revision pinned in lake-manifest.json (backends/lean); this revision uses Lean 4.35.0. The recorder checks committed Lean theorem declarations and permits only propext, Classical.choice, and Quot.sound as transitive axioms. It rejects sorryAx and custom axioms, including axiomatized external models. Charon/Aeneas extraction is not rerun. The author must review that the committed functional model matches the recorded Rust source, that the named theorem corresponds to the public API, and that the reported precondition matches the theorem. A checked theorem alone does not establish those links or the adequacy of the specification. The current adapter records the default Cargo configuration, with ordinary Lean module paths and a pinned official Git dependency. Other backends, custom Lake source directories, and local-path Aeneas dependencies are unsupported.
