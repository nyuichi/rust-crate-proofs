Overview

byteorder 1.5.0: fixed-width unsigned and signed integer writes, plus BE/LE write_f32/write_f64, write their exact bit representations in the selected endian order and preserve trailing bytes when the output is long enough; shorter buffers panic before writing. Float proofs quantify over every 32/64-bit representation, including NaN payloads and signed zeros, under explicit bit-pattern and std to_bits models. No floating arithmetic is modeled. BE/LE read_u24 additionally returns the exact unsigned24 prefix decode below2^24, and asserts on shorter input. LittleEndian from_slice_u16/u32/u64/u128 additionally leave every slice unchanged on the verified little-endian target, including empty slices and arbitrary unsigned values. The two handwritten Default methods always panic. Four unsigned variable-width readers decode the exact selected prefix under their complete byte-count/input-length guard, and assert otherwise. Eight additional original concrete reader defaults are verified: BE/LE read_u48 returns the exact six-byte unsigned decode below 2^48; read_int, read_i24 and read_i48 return the selected-width two-complement signed decode. General signed counts must be1..8 with sufficient input; fixed readers need three or six bytes. Failed input/count guards return assertion failure before sign extension. Their original full read_uint callees are connected by definitional equality to the existing byteorder general-reader proofs; the actual original extend_sign body is proved directly with separately named pure bit-vector lemmas, without new models or Lite proof imports. BE/LE read_int128 additionally decode every valid1..16byte signed prefix, and assert on all invalid count/input guards before sign extension. The actual original read_uint128 bodies are connected by definitional equality to existing byteorder contracts; the actual original extend_sign128 body is proved directly using independently named pure bit-vector lemmas. No Lite proof module or new model is imported. Separate Kani checks compare the original BE/LE write_uint/write_uint128 methods with byteorder-lite for all fitting unsigned values and valid byte counts, arbitrary initial 32-byte arrays, and slice lengths from the byte count through 32. Both complete buffers agree and suffix bytes are preserved; four harnesses complete with 456 checks and no failures.
