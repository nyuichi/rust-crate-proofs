Overview

byteorder-lite 0.1.0: fixed-width unsigned and signed integer writes, plus BE/LE write_f32/write_f64, write their exact bit representations in the selected endian order and preserve trailing bytes when the output is long enough; shorter buffers panic before writing. Float proofs quantify over every 32/64-bit representation, including NaN payloads and signed zeros, under explicit bit-pattern and std to_bits models. No floating arithmetic is modeled. Signed write_i24 and write_int additionally serialize the low 24 or 8nbytes bits for every signed input value, preserving suffix bytes; no signed representability condition is required. Invalid byte counts or short buffers panic as specified. Signed read_int/read_i24 additionally return the exact two-complement prefix decode at the selected width; all invalid counts and short inputs assert before sign extension. LittleEndian from_slice_u16/u32/u64/u128 and from_slice_i16/i32/i64/i128 additionally leave every slice unchanged on the verified little-endian target, including empty slices and all element values. Native LittleEndian from_slice_f32/f64 also preserve every memory bit under the existing representations, including NaN payloads and signed zeros; this is not a Rust floating PartialEq claim. The two handwritten Default methods always panic. The four variable-width unsigned writers additionally have exact byte-count/space guards, selected-byte output on success and assertion failure otherwise. Unsigned 24-bit readers/writers additionally have exact 3-byte decoding/serialization, a 24-bit value domain and complete short-buffer/value-overflow failures. Four unsigned variable-width readers decode the exact selected prefix under their complete byte-count/input-length guard, and assert otherwise. Eight concrete original 48-bit default methods are also verified: unsigned reads decode six bytes below 2^48; unsigned writes require a value below 2^48; signed reads decode six-byte two-complement values; signed writes truncate every i64 input to its low 48 bits. Enough buffer space preserves the suffix; short buffers fail assertion. Each original default body is connected by definitional equality to its original concrete general-width callee with count six. BE/LE read_int128 and write_int128 also cover all values and counts: signed reads decode the selected prefix for counts1..16 with enough input and assert otherwise; signed writes serialize the low8count bits of every i128, preserving suffix bytes. Invalid write counts0 or above16 fail integerOverflow in unextend_sign128 before the writer; valid counts with insufficient output assert. Actual original unsigned128 callees are linked by definitional equality to existing general contracts; original extend_sign128/unextend_sign128 bodies are proved directly with no new models.
