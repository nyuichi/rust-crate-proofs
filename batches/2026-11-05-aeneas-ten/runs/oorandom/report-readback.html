Overview

For the unchanged Rand32::rand_u32 body, every u64 state s and increment i returns the PCG-XSH-RR output rotate_right(low32(((s >> 18) XOR s) >> 27), low32(s >> 59)), and updates the state to (6364136223846793005*s+i) modulo 2^64 while preserving the increment. Right shifts are logical. The call terminates without model failure. Original crate Rust source and Cargo manifest are unchanged; official Aeneas scalar and array primitives supply all library operations, without custom external models.

What is trusted

The Rust compiler, Charon/Aeneas translation, official Aeneas scalar/array models and Lean kernel are trusted. Standard-library operator implementations are modeled by the official Aeneas library, rather than individually body-proved. The public theorem has no extra local axioms; transitive dependencies allow only propext, Classical.choice and Quot.sound.

Technical limitations

Only Rand32::rand_u32 is verified, for the default feature configuration on x86_64-unknown-linux-gnu. Seed constructors, state access/restoration, other generators, signed/floating/ranged output, advancement, buffer filling, serialization and inherited wrappers are outside this proof. No period, distribution, independence, nonzero-state invariant or cryptographic property is established.

Tool limitations

Lean backend only, requiring cargo-proofs 0.4.0 or later. The version identifies the official Aeneas Git revision pinned in lake-manifest.json (backends/lean); this revision uses Lean 4.35.0. The recorder checks committed Lean theorem declarations and permits only propext, Classical.choice, and Quot.sound as transitive axioms. It rejects sorryAx and custom axioms, including axiomatized external models. Charon/Aeneas extraction is not rerun. The author must review that the committed functional model matches the recorded Rust source, that the named theorem corresponds to the public API, and that the reported precondition matches the theorem. A checked theorem alone does not establish those links or the adequacy of the specification. The current adapter records the default Cargo configuration, with ordinary Lean module paths and a pinned official Git dependency. Other backends, custom Lake source directories, and local-path Aeneas dependencies are unsupported.
