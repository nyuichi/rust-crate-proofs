Overview

For either 1.19.0, is_left and is_right report the actual variant for every Either value. left and right return Some of exactly the corresponding payload or None for the opposite branch. left_or and right_or return the matching payload or the supplied default. flip swaps Left and Right while preserving the payload; a separate composition theorem proves that flipping twice returns the original value. These seven original method bodies terminate normally in the Aeneas model for arbitrary payload types and values, without inspecting or modifying payloads.
