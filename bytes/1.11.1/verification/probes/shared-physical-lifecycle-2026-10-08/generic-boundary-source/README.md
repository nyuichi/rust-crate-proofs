# Generic boundary source snapshot

These exact Creusot standard-library source files support review of the bounded
shared-lifecycle probe's generic ghost sharing, lifetime, view, atomic, and
callback interfaces. They are copied from the active `creusot-std 0.13.0`
registry source. The matching canonical checkout is Creusot commit
`318615be3b8bbc60d1f6d52469ba5c0bdebed4f1` (`Release 0.13.0`); the copied
files have the per-file SHA-256 values in `manifest.json`.

This is a selected-source snapshot, not a complete standard-library archive.
It documents the generic boundary only; it does not establish the bytes-specific
protocol or any ownership theorem.

The active proof package is the private Std overlay. Root compared all ten
selected files with that overlay, the registry and canonical checkout; they are
byte-identical. Registry package VCS metadata names
`afd365f7a8ba33a90c67b0809de4e7a097421057`, which differs from the tool checkout
commit above. This records selected-source correspondence, not whole-package
identity or absence of other overlay patches.
