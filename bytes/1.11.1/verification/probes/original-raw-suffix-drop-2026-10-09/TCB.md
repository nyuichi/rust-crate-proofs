It adds no Bytes-specific clone/free, capacity, ownership or last-owner axiom. It reuses AV's generic same-allocation pointer distance, affine PhysicalRegion/Recovery and owned AtomicPtr field permission. Physical deallocation consumes the full original allocation and returns the existing physical FreeReceipt.

Generic physical/pointer interpretation, the pinned private Std, atomic field/weak-memory representation, erased Ghost scope and callback registrations, and native normal-Drop/source correspondence remain explicit trusted interfaces. Raw callback registrations are separately constrained by original-base parity; no Ghost value controls a native runtime branch. The actual native vtable invocation stays unchanged. Current checks bind the selected nonempty From<Box> constructor to the single owned atomic field, actual advance/len/inc_start operations to shadow operations, raw KIND_VEC decoder/free branches, and saved-return then terminal Drop MIR. This is a fixed audited source/native trace with generic adapters; it is not a general Rust erasure or arbitrary-callgraph verifier.

Immutable externally pinned closure/profile hashes establish evidence transport and required-input reconstruction, not new native theorem authority. Original diagnostic proof metadata stays intact and later current correspondence/fresh Cargo admission has separate provenance. No full solver rerun is claimed. Tool binaries are external; Cargo artifacts are location-bound snapshots. Full original crate admission remains false.
