Source correspondence for bytes 1.11.1 actual mutable-slice BufMut probe

The build script extracts remaining_mut, chunk_mut, and advance_mut separately
from each concrete source impl in src/buf/buf_mut.rs. It inserts those function
items unchanged into the two closed proof interfaces and checks that each
normalized generated method body equals the normalized source method body.
It also checks the generated UninitSlice struct, View impl, new, uninit,
write_byte, and len items, plus TryGetError, panic_advance, and
slice_mut_ops::advance_slice_mut, contain their exact extracted source items.
All checks run during Cargo build.rs execution before native tests or Creusot.
