# AY assumptions and scope

Raw and promoted Root views retain the same affine scope and original allocation descriptor. The proofs establish exact suffix access, pointer/length advancement and destructor effects using generic physical authority that is assumed to describe a live initialized allocation and valid pointer operations. Consequently, this evidence does not independently discharge every native Rust memory-model obligation.

The generic AtomicPtr field interpretation, weak-memory/resource adapters, pinned private Std contracts and erased Ghost callback correspondence remain trusted interfaces. Two exact callback registration instances connect body-proved raw/shared callbacks to the stored native vtable; immutable original-base parity selects them, while the ordinary native kind branch remains unchanged. No Bytes-specific ownership, refcount, last-owner, capacity or destructor law is newly assumed. Shared release body proofs remove the exact Root ledger member and prove reclamation iff it was last; raw destruction consumes the full original physical allocation and yields the existing FreeReceipt.

Lexical peer Drop requires explicit observed Root and peer ledger memberships. The witness proves those from the actual promotion map; finite-map cardinality proves the surviving Root prevents peer reclamation. Model/public cursor acceptance alone is not treated as a membership guarantee. Current source/MIR correspondence checks constructor, both advances, optional peer Clone/Drop, merged read and normal Root Drop with exact places/order. This is fixed audited-source correspondence, not arbitrary Rust control-flow verification.

Evidence transport uses externally pinned closure manifests, exact object sizes/hashes and an independently complete input-binding profile. These are audit assumptions, not new native ownership rules. Installed tool payloads remain external and Cargo captures retain location-bound snapshot limits. Original diagnostic proof records and later admitting metadata have separate provenance. Full original crate admission, unwind and general concurrent/escaping ownership remain open.
