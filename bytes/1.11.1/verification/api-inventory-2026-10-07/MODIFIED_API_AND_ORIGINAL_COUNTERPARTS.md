## Cost and mapping vocabulary

- `Direct` means original symbol/runtime semantics remain selected; this modified feature has almost no direct original-item preservation.
- `Rewritten` means a body-proved method has overlapping byte-sequence responsibility but changes name/type/ownership/failure convention/cost.
- `Helper` means a new scoped proof-connected client/model.
- `Absent` means no selected counterpart.
- `Candidate` is separate from current HEAD.
- `move` transfers a single Vec/String/Box allocation; `copy O(n)` allocates and copies; `borrow` is scope-bound; `scoped` shares temporary read borrows and has explicit retirement; `explicit close` consumes Vec-backed owner through the generic raw-Vec boundary. No modified API row implies old O(1) slice/split, shared address, clone/refcount, or automatic drop behavior.
