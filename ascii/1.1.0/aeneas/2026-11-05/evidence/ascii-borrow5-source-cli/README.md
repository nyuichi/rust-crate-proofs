# ASCII 46 finite source discovery update

This packet adds five original `AsRef`/`AsMut` implementations to the existing finite ASCII source binding opt-in. It does not prove Rust behavior; the separately frozen ASCII46 Aeneas package supplies those proofs. Publication remains the publisher's responsibility.

The existing field and manifest schema are unchanged. The manifest digest selects exactly one of two compiled snapshots: the unchanged ASCII41 snapshot, or the known ASCII46 snapshot. Unknown digests and changes to the exact key list, source, proof closure, compiler, configuration, or recorded source are rejected.

Discovery retains three separate groups: the original37 legacy scanner results; the unchanged Vec4 dedicated entry; and a new exact five-key borrow entry. Only the two finite entries enable the previously audited Rust2015 root-use/public nested-type resolution. The Vec4 allowed set is not expanded. Both source groups find actual original AST methods, check imports, owner/trait selection, source spans, signature/receiver/safety/generics and exact bodies, and return singleton canonical keys. No private-key alias is adopted and the global resolver is unchanged.

The new bodies return the full typed ASCII slice or the receiver itself. Their separate Aeneas contracts cover model sequence/length and same-length mutable writeback. This source binding update adds no memory-address, allocator/capacity, pointer/lifetime/aliasing or OOM guarantee, and does not turn unrelated inherited APIs into verified operations.

`HANDOFF.json` records exact source, patch and binary hashes. `source-before` is the complete pre-update copy of the two edited files; `source-after` contains those files and the new compiled46 snapshot.
