This packet extends the existing finite ASCII source binding opt-in from its unchanged known41 and known46 snapshots to one compiled known49 snapshot. Original Rust, generated Lean and proof sources are unchanged; the separately frozen producer package supplies the verification. Installation and publication belong to the publisher.

The existing configuration field and manifest schema are unchanged. Exactly three compiled digests are accepted, with exact proof mappings/preconditions, original archive/source, proof/evidence closure, compiler/configuration and captured immutable revision checks. Unknown snapshots and malformed/private source keys are rejected. The original Vec4 and borrow5 entry definitions and both old compiled data files remain byte identical.

Known49 uses a separate exact borrow6 entry, adding only `<ascii::AsciiStr as AsMut<ascii::AsciiStr>>::as_mut` to the five previous borrow bindings. The other two additions are real local `std::error::Error::description` bodies for `ToAsciiCharError` and `AsAsciiStrError`. They use the normal source scanner and its actual original `std::error::Error` import spelling.
