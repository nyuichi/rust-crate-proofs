# Integer single-bit operations and generic slice routing, with exact failure cases

The unchanged bit_field 0.10.3 single-bit methods are verified for all twelve integer types: in-range indices read or update exactly that bit, returned mutable-reference writes propagate to the original value, and invalid indices fail at the assertion. All twelve primitive BIT_LENGTH values equal their widths. The original generic slice bit_length/get_bit/set_bit bodies are also composition-proved: assuming their declared BitField constant and per-element normal-return contracts, they use element index bit/width and local index bit%width, preserve other slice entries on update, and report zero-width/out-of-bounds errors. bit_length returns length times width or integerOverflow. Rust source and Cargo.toml are archive-identical.

The official Rust/Charon/Aeneas translation and integer/slice models, Lean, and Kani/CBMC are trusted. Twelve explicit monomorphized size_of models supply the integer byte sizes on x86_64, including pointer size 8; Kani checks their actual layouts and all primitive single-bit methods/returned-reference behavior for arbitrary valid values. Connecting Kani Rust and Lean representations is a reviewed bridge, not an in-Lean std layout proof; Rust nightlies differ. Generic slice theorems assume the complete stated observation/update callback contracts, including the final state after returned-reference writeback. They do not prove arbitrary callback implementations. Mapped audits allow only propext, Classical.choice and Quot.sound.

Only twenty-four primitive single-bit methods, twelve width constants and three callback-conditional slice bodies are established. Primitive and slice get_bits/set_bits range methods remain unproved. A separately Kani-checked example shows signed range behavior differs from ordinary masked updates: 112_i8.set_bits(0..4,1) yields 1, changing high bits outside the range; the unsigned example yields 113. The verified single-bit methods are unaffected. Generic callback side effects, failure/divergence outside the stated contracts, other targets and release extraction are not established. No generic Rust size_of property, panic text or unwinding-state guarantee is claimed.
