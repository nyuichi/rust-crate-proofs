# URI proof status — 2026-10-05

This harness is a named URI leaf profile for `http` 1.5.0. Its fresh current-source frontend check and clean Creusot emission are recorded in `evidence/uri-conversion-proof-2026-10-05/`. The archived conversion COMAs match that clean emission byte-for-byte. The native surface regression suite has four passing tests.

Current actual-source proof results in this profile:

- `From<Authority> for Uri` and `From<PathAndQuery> for Uri`, including both bodies and refinement posts: six owned terminal VCs passed in total. The four `Scheme::empty`, `PathAndQuery::empty`, and `Authority::empty` support roots are local COMA definitions; Why3 reduces them to `solidtrue` before the prover, so they add no solver leaves.
- `Debug for Uri::fmt` body and refinement: seven owned VCs passed. Its COMA uses the opaque `Display::fmt` contract as a support assumption. The Debug result does not prove the separate Display body.

The current URI source tree contains additional model and contract work that remains unproved as actual source bodies. In particular, `Display for Uri::fmt` is only frontend-checked and emitted so far (48 body tasks and three refinement tasks); same-type `Uri` equality (17 + 4), `Uri`-to-`str` equality (49 + 3), and `Hash for Uri` (22 + 3) have task-count audits but no current proof results yet. Parser and getter bodies are also pending their own target-level proof batches. Treat these contracts and task emissions as preparation, not proofs.

Older URI evidence directories are bound to their own recorded source hashes and cfg profiles. They do not prove later URI edits merely because target names overlap. The completed `bytes` crate evidence is an assumed dependency boundary for this work; no bytes source or proof changes are included in this status.

The current source files include WIP in `src/uri/authority.rs`, `src/uri/mod.rs`, `src/uri/path.rs`, `src/uri/scheme.rs`, and `verification/uri/src/lib.rs`. Their presence in this branch does not imply that all URI APIs, parsers, or formatter/comparison contracts have been proved.
