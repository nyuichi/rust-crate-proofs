# Original oorandom float range contracts

Two independent Kani harnesses call the unmodified original Rand32::rand_float and Rand64::rand_float, after original from_state restores arbitrary complete state and increment (64+64 or 128+128 input bits). No nonzero/odd restrictions, assumes, stubs, artificial input bounds or observer additions are used. Each proves the returned IEEE f32/f64 is at least zero and strictly less than one. Kani 0.68.0 / CBMC 6.11.0 checks each harness with 33 checks; from_state and called original output bodies are part of the actual call graph.

This is a range guarantee only. It does not establish exact output bits, output distribution, independence, stream period, state-transition equality, or rand_range termination. Separate attempts at an independent PCG/IEEE exact-output plus state contract and original-word composition contract timed out after 90 seconds each; the corresponding rand32-probe.log and rand32-composition.log are retained as incomplete attempts, not failed properties or successful proofs. Those attempted sources remain at incomplete-attempts/lib.rs and are not part of the two fixed successful harnesses here.

The dependency is extracted locally from the original crates.io archive. check-source.py compares every archived file byte for byte before executing either successful harness. Source and manifest of the original crate are unchanged. This separate tool uses nightly-2026-08-21; the Aeneas work uses another nightly. No formal cross-tool link is claimed. cargo-proofs currently cannot map these ordinary #[kani::proof] harnesses as contract-registered API claims; this package is separate supplemental evidence, not an Aeneas claim. Reproduce with ./verify-kani.bash.
