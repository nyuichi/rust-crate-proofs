# Reproduction and integration boundary

The producer generic manifest and the independent Kani900 hash manifest are preserved. The generic manifest lists twenty Lean/IR sidecars despite its zero-sidecar flag; integration.json enumerates the excluded files. None is included in the public subset or used to certify the supplemental declarations. Original generated .lean, translation JSON, source guards, LLBC, raw compiler and solver evidence are retained byte for byte.

verify-generic-family.bash and regenerate-family.py preserve the producer full regeneration recipe; that consolidated recipe was not rerun during packaging. Individual successful extraction/guard logs and original standard-library pins remain evidence. The formal fresh run recompiles the copied generated .lean and theorem source. The root project keeps the official pinned Aeneas library. `lake build +Proofs` is the exact publisher target; Proofs imports HasherFamilyAudit, which imports the five new proof modules and prints all13 axiom dependencies. To prevent a cycle, the standalone producer FinalFamilyAudit leading import Proofs is omitted only in the integrated audit module. Original14 theorem bodies and all generated definitions are unchanged. The local same-target1818-job successful log explicitly contains all13 markers.

The original Kani paths are retained as executed provenance; the copied package hierarchy preserves their original relative dependency layout. Kani900 and the generic compiler-inline/DCE caller contracts have distinct domains/trust boundaries. This package adds no direct default-method API-card binding and no primary machine claims.
