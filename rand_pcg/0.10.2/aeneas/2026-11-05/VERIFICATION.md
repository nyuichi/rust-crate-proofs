# Exact construction, state access and native output for all four PCG generator types

For rand_pcg 0.10.2, state returns the exact stored word for Lcg64Xsh32, Lcg128Xsl64, Lcg128CmDxsm64 and Mcg128Xsl64. For the three LCG types, stream returns the stored increment shifted logically right by one; from_state preserves the given state and stores increment=(stream<<1) OR 1, discarding the highest stream bit. Their new constructors normalize that increment and initialize state=((input_state+increment)*multiplier+increment), with state-width modular arithmetic. The multipliers are 6364136223846793005, 47026247687942121848144207491837523525, and 15750249268501108917, respectively. Mcg128Xsl64::new stores input_state OR 1. Each of these fourteen original APIs terminates normally in the model for arbitrary scalar inputs. The prior Lcg64Xsh32::try_next_u32 exact PCG-XSH-RR output/state theorem is also retained, for fifteen initial proved API bodies. Six further body proofs establish try_next_u64 and try_next_u32 for Lcg128Xsl64, Mcg128Xsl64 and Lcg128CmDxsm64, for twenty-one API bodies total. The XSL-RR variants permute the newly advanced state; the CM-DXSM variant permutes the old state and then advances. Their 32-bit methods return the low 32 bits of the corresponding 64-bit result with exactly the same state update. The original standard Result::map body and the original conversion closures are included in the proof. Selected official translations are byte-identical under default and serde configurations; serde trait implementations remain unproved.

Coverage is limited to the twenty-one named bodies, default or serde features, x86_64-unknown-linux-gnu. Model states need not have odd increments: the getter theorem reports the logical shift for every modeled state, but no save/restore identity is claimed for an arbitrary even-increment state. from_state/new normalize the increment exactly as specified. Advance, seed bytes/from_seed/seed_from_u64, Lcg64Xsh32::try_next_u64, byte-buffer filling, RNG callbacks/forking, manual Debug, serde and inherited/default/external blanket APIs remain unproved. The proof does not establish period, statistical quality or cryptographic security. Other targets and dependency feature combinations were not checked.

The Rust compiler, official Charon/Aeneas translation, official Aeneas scalar models and Lean kernel are trusted. No custom external models, source adaptations or local trusted helper contracts are used. All twenty-one API theorem dependency audits permit only propext, Classical.choice and Quot.sound. Wrapping arithmetic, shifts, casts and rotations use official standard-library models, rather than proofs of Rust std implementation bodies. The original Result::map body is extracted and proved through its actual closure calls, rather than supplied by a custom model.

Exact output_xsl_rr and output_dxsm scalar formulas and all state transitions are in proofs/Proofs.lean. For xsl_rr, xor the high and low 64-bit halves and rotate right by the top six bits of the 128-bit state. DXSM mixes the old high half with logical shifts 32/48 and multiplier 15750249268501108917, then multiplies by the low half OR 1.

Run `./verify-all.bash`. The baseline inventory (before these extensions) is retained in evidence/api-inventory-baseline.json.

## Full-delta multiplicative advance

AdvanceProofs.mcg_advance_spec proves the unchanged original Mcg128Xsl64::advance body returns normally for every full-width unsigned delta and arbitrary internal state, with state=M^delta*initial_state modulo2^128. Zero/even states are valid unsigned Rust values even where ordinary seeds cannot reach them. The loop invariant preserves the accumulator/power relation and zero additive accumulators; remaining_delta/2 strictly decreases when positive. No testing bound, compiler-inlined replacement, custom std model or new axiom is used. The proof does not establish period or jump-back semantics for wrapped negative deltas. Default/serde models are byte-identical. Distinct official namespace and simultaneous configured-module imports prevent duplicate-model collisions.

## Full-delta affine advance

All three LCG advance methods are proved on unchanged original bodies for arbitrary full-width state, increment and delta, including zero/even increments. Each returns normally, preserves increment, and reaches exactly the state from delta repetitions of x↦M*x+increment modulo the word width. The reference is ordinary linear recursion, not the implementation’s binary algorithm. General affine composition, binary-power algebra, per-width loop invariants and strictly decreasing remaining_delta/2 connect it to the source. No period, statistical quality, seed reachability or wrapped-negative jump-back guarantee is inferred. See Affine.lean/AffineProofs.lean and the separate namespace/default-serde/coimport guards.
