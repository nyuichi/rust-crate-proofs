# Exact PCG construction, state access and stream normalization for four generator types

For rand_pcg 0.10.2, state returns the exact stored word for Lcg64Xsh32, Lcg128Xsl64, Lcg128CmDxsm64 and Mcg128Xsl64. For the three LCG types, stream returns the stored increment shifted logically right by one; from_state preserves the given state and stores increment=(stream<<1) OR 1, discarding the highest stream bit. Their new constructors normalize that increment and initialize state=((input_state+increment)*multiplier+increment), with state-width modular arithmetic. The multipliers are 6364136223846793005, 47026247687942121848144207491837523525, and 15750249268501108917, respectively. Mcg128Xsl64::new stores input_state OR 1. Each of these fourteen original APIs terminates normally in the model for arbitrary scalar inputs. The prior Lcg64Xsh32::try_next_u32 exact PCG-XSH-RR output/state theorem is also retained, for fifteen proved API bodies total.

Coverage is limited to the fifteen named bodies, default features, x86_64-unknown-linux-gnu. Model states need not have odd increments: the getter theorem reports the logical shift for every modeled state, but no save/restore identity is claimed for an arbitrary even-increment state. from_state/new normalize the increment exactly as specified. Advance, seed bytes/from_seed/seed_from_u64, other random-output methods, byte-buffer filling, RNG callbacks/forking, manual Debug, serde and inherited/default/external blanket APIs remain unproved. The proof does not establish period, statistical quality or cryptographic security. Other targets and feature configurations were not checked.

The Rust compiler, official Charon/Aeneas translation, official Aeneas scalar models and Lean kernel are trusted. No custom external models, source adaptations or local trusted helper contracts are used. All fifteen theorem dependency audits permit only propext, Classical.choice and Quot.sound. Wrapping arithmetic, shifts, casts and rotations use official standard-library models, rather than proofs of Rust std implementation bodies.

Run `./verify-all.bash`. Baseline full API inventory (before this extension): evidence/api-inventory-baseline.json.
