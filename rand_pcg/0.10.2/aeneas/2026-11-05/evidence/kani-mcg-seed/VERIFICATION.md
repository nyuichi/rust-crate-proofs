# Mcg128Xsl64 byte seed initialization

For every 16-byte seed, the unchanged original rand_pcg 0.10.2 Mcg128Xsl64::from_seed followed by the unchanged original public state() returns the seed interpreted as a little-endian 128-bit integer, with its low bit set. This includes all-zero seeds, for which the observed state is one. The reference packs the individual input bytes with scalar shifts and OR; it calls neither from_seed nor read_words. Every input seed bit is arbitrary, with no assumes, stubs or artificial length bounds. Kani checks the actual original constructor, dependency read_words and public observer call graph. No source instrumentation or private observer is used.

The complete original Rust source and manifest remain unchanged as a local archive dependency. check-source.py compares those files against upstream.crate and validates the fixed harness and dependency lock. Default and serde configurations are verified separately, with rand_core 0.10.0 and serde 1.0.228 pinned in Cargo.lock to match the Aeneas baseline. The earlier probe-newer-dependencies logs used allowed but different rand_core 0.10.1 and serde 1.0.229; they are retained as separate probes, not evidence for the pinned baseline.

Kani 0.68.0 / CBMC 6.11.0 uses nightly-2026-08-21, separately from the Aeneas toolchain. This is a direct original-API composition guarantee about public observed state, not a formal cross-tool link, output-stream/period/statistical-quality proof, or serde implementation proof. Other PCG byte-seed constructors remain unproved. Ordinary #[kani::proof] harnesses are supplemental evidence, not currently registerable proof_for_contract mappings in cargo-proofs and not additional Aeneas API claims.
