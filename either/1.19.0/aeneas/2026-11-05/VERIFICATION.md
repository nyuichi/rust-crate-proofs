# Either1.19.0: 35 original callable contracts

The unchanged original Rust bodies are extracted together from default features on x86_64 into one Generated.Either module. Thirty-five API mappings retain all previous32 mappings byte-for-byte as parsed metadata and add either/either_with/either_into. Six proof modules share that same nominal type; all35 machine claims are imported simultaneously and92 distinct main/helper theorems satisfy the standard-three transitive axiom policy.

The new APIs select the callback or Into dictionary for the actual variant and pass its payload exactly. either_with also forwards the original context as the first pair element. The main contracts preserve the selected computation's complete modeled Result without asserting success. Normal-value helpers assume success only at the selected payload/context, returning the corresponding mathematical value. Separate helpers propagate the same modeled failure or divergence. The unselected callback/conversion dictionary is unconstrained.

These are original-body dispatch/composition results. They do not verify arbitrary callback or Into implementations, their concrete values, termination or captured effects. No mutable-context writeback, eager argument construction or independent pointer/alias/lifetime guarantee is added. Rust Drop for discarded callbacks/payloads can panic, diverge or affect external state; destructor execution, unwinding and return ordering are outside this value model. Model fail/div helpers must not be equated with every Rust panic or nontermination behavior.

All earlier32 guarantees remain: exact variant/projection/selection and payload factoring; flip-twice; borrowed views and same-variant backward writeback; the earlier12 conditional callbacks; actual IntoEither blanket/default dispatch; both handwritten Result/Either conversions and their roundtrips; matching-payload/default-computation delegation. Their individual premises and previous Drop/value-model boundaries are retained. The earlier12 inherent callback normal contracts require success on every callback argument, while the new dispatch normal helpers need it only at the selected call. Default/Into/FnOnce implementation values or termination are never inferred without the stated premises.
