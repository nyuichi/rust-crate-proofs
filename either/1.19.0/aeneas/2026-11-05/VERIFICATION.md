Forty API mappings retain all previous39 rows and all seven old proof module sources unchanged, adding the original manual Iterator::next body. The previously added either/either_with/either_into APIs select the callback or Into dictionary for the actual variant and pass its payload exactly. either_with also forwards the original context as the first pair element. The main contracts preserve the selected computation's complete modeled Result without asserting success. Normal-value helpers assume success only at the selected payload/context, returning the corresponding mathematical value. Separate helpers propagate the same modeled failure or divergence. The unselected callback/conversion dictionary is unconstrained.

These are original-body dispatch/composition results. They do not verify arbitrary callback or Into implementations, their concrete values, termination or captured effects. No mutable-context writeback, eager argument construction or independent pointer/alias/lifetime guarantee is added. Rust Drop for discarded callbacks/payloads can panic, diverge or affect external state; destructor execution, unwinding and return ordering are outside this value model. Model fail/div helpers must not be equated with every Rust panic or nontermination behavior.

The earlier12 inherent callback normal contracts require success on every callback argument, while the new dispatch normal helpers need it only at the selected call. Default/Into/FnOnce implementation values or termination are never inferred without the stated premises.

## Original Iterator next and bounded model scope

The new manual trait body delegates only to the selected existing standard Iterator.next dictionary. It returns the identical Option<Item> and updated inner iterator state under the original tag; None retains that returned state too. Each normal helper assumes the corresponding selected inner next result. Identical modeled failure/divergence propagate without consulting the other iterator. Concrete iterator correctness, progress, termination, size bounds, element counts, finite length and fusedness remain unverified. The returned self is the value/backward-state translation, not an independent full Rust alias/lifetime/global-effects guarantee.
