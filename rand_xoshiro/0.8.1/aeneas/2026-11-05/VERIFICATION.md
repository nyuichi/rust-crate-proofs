# Exact native outputs and additional 32-bit projections across the xoshiro generator family

For rand_xoshiro 0.8.1, the unchanged native word-generating method of each of its fifteen generators returns Ok of the specified output scrambler and performs the exact documented word-state transition. Coverage includes SplitMix64, both xoroshiro64 variants, all three xoroshiro128 variants, and all three variants of each xoshiro128, xoshiro256 and xoshiro512 family. For 32-bit-word engines the native method is try_next_u32; for 64-bit-word engines it is try_next_u64. SplitMix64::try_next_u32 is also proved independently, including its distinct Mix4 output formula, for sixteen proved API bodies. Each theorem covers arbitrary internal words, including all-zero states, and establishes normal termination in the Aeneas model. Array-state representation theorems establish that the four-word and eight-word inputs cover every valid fixed-length engine state. Exact output formulas and resulting fields are defined independently of the generated Rust body in the output*/next* specifications. The selected original bodies have byte-identical official Aeneas translations under the default and serde feature configurations, so these body guarantees apply to both configurations; this does not verify the serde trait implementations. Nine further 32-bit APIs are verified through exact forwarding selectors whose calls to the unchanged original API are inlined by the Rust compiler: all three xoroshiro128, all three xoshiro256 and all three xoshiro512 variants. These establish the same state transition as their 64-bit method, with low 32 output bits for xoroshiro128++ and xoroshiro128**, and high 32 bits for the other seven variants. This yields twenty-five API guarantees: sixteen direct original-body proofs and nine compiler-inlined original-API call proofs. The selector source, typed receiver/return correspondence, target, original method inline scopes and absence of unknown externals are guarded. Default and serde selected programs are byte-identical.

Only sixteen native-output bodies and nine compiler-inlined original-API forwarding calls are covered, with default or serde features on x86_64-unknown-linux-gnu. The five 32-bit-engine try_next_u64 compositions, buffer filling, seed construction, state serialization/accessors, jump/long_jump, Seed512 APIs, manual Debug, serde and inherited/default/external blanket methods remain unproved. All-zero states are included in the exact step formulas; seed validity, nonzero-state invariants, full-period behavior, statistical distribution, independence and cryptographic security are not established. Other targets and dependency feature combinations were not checked.

The Rust compiler, official Charon/Aeneas translation, official Aeneas array/scalar models and Lean kernel are trusted. No custom external models, source adaptations or local helper axioms are used. All API and supplementary direct/selector theorems have dependency audits permitting only propext, Classical.choice and Quot.sound. Standard shifts, rotations, wrapping arithmetic and array operations use official Aeneas models, rather than body proofs of Rust std implementations. The nine selector proofs additionally rely on Rust compiler inlining of the exact original API call; retained MIR scopes identify each original TryRng method and Rng wrapper. The selector does not replace or assume an opaque original API: generated native callees are body-proved and no unknown external definitions remain.

Direct proofs: proofs/Proofs.lean and proofs/RandXoshiro.lean. Compiler-inlined caller proofs: proofs/WrapperProofs.lean and proofs/XoshiroApiRoots/. Exact forwarding source and per-API identity: evidence/selection-wrapper/src/lib.rs and api-bindings.json. Per-feature compiler/MIR provenance: evidence/selection-wrapper/compiler-provenance.json and default/mir/, serde/mir/.

Run `./verify-all.bash`. Unknown external/axiom guards and all public transitive audits remain mandatory.

## Seed512 direct bodies

Default returns 64 zero bytes. AsRef preserves the complete stored byte sequence. AsMut preserves that initial view and its backward function writes back any legal 64-byte replacement. The fixed-length condition is the natural length invariant of a returned slice into this fixed-size array. iter initializes the official standard slice-iterator model at index zero over the full byte sequence; this proof does not separately body-verify standard Iterator methods. These four APIs add direct proofs, bringing the Aeneas total to 29 (20 direct plus 9 compiler-inlined calls). See proofs/SeedProofs.lean and evidence/seed512-equivalence.json.

## SplitMix64 state serializer

StateProofs.splitmix_state_spec proves the original state method returns all eight little-endian bytes of the internal u64 state, with no restriction on that state. This adds a direct original-body claim; other generators’ state serializers remain unproved. No custom size_of model is supplied. Default/serde official output files are byte-identical.
