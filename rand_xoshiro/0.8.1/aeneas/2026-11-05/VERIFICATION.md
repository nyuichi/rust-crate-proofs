# Exact native word outputs and state updates for all fifteen xoshiro-family generators

For rand_xoshiro 0.8.1, the unchanged native word-generating method of each of its fifteen generators returns Ok of the specified output scrambler and performs the exact documented word-state transition. Coverage includes SplitMix64, both xoroshiro64 variants, all three xoroshiro128 variants, and all three variants of each xoshiro128, xoshiro256 and xoshiro512 family. For 32-bit-word engines the native method is try_next_u32; for 64-bit-word engines it is try_next_u64. SplitMix64::try_next_u32 is also proved independently, including its distinct Mix4 output formula, for sixteen proved API bodies. Each theorem covers arbitrary internal words, including all-zero states, and establishes normal termination in the Aeneas model. Array-state representation theorems establish that the four-word and eight-word inputs cover every valid fixed-length engine state. Exact output formulas and resulting fields are defined independently of the generated Rust body in the output*/next* specifications.

Only the sixteen named native-output bodies are covered, with default features without serde on x86_64-unknown-linux-gnu. Other-width output projections/compositions, buffer filling, seed construction, state serialization/accessors, jump/long_jump, Seed512 APIs, manual Debug, serde and inherited/default/external blanket methods remain unproved. All-zero states are included in the exact step formulas; seed validity, nonzero-state invariants, full-period behavior, statistical distribution, independence and cryptographic security are not established. Other targets and feature configurations were not checked.

The Rust compiler, official Charon/Aeneas translation, official Aeneas array/scalar models and Lean kernel are trusted. No custom external models, source adaptations or local helper axioms are used. All sixteen API theorems and sixteen supplementary array/representation theorems have dependency audits permitting only propext, Classical.choice and Quot.sound. Standard shifts, rotations, wrapping arithmetic and array operations use official Aeneas models, rather than body proofs of Rust std implementations.

The full formulas are in proofs/Proofs.lean: each input*/output*/next* specification gives the complete old-state-to-result/new-state relation. Plus outputs add selected old words modulo word width; star outputs multiply; star-star outputs apply multiply/rotate/multiply; plus-plus outputs apply add/rotate/add. Each variant retains its own exact constants and selected word positions. SplitMix64 includes its precise xor/shift/multiply scramblers and PHI increment.

Run `./verify-all.bash`. The inventory baseline before extension is retained in evidence/api-inventory-baseline.json.
